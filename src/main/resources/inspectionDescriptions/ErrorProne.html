Reports what Error Prone found in the file during the last Gradle build that compiled it.

Nothing is analysed here: Error Prone runs as part of your Gradle build, configured as usual, and this inspection shows its diagnostics. They appear after a build, follow your edits, and disappear when a later build no longer reports them. Build | Run Error Prone analyses every Java source set again.

Turning this inspection off hides Error Prone diagnostics in the editor. To silence one check, use @SuppressWarnings("CheckName") or configure Error Prone in the build.
